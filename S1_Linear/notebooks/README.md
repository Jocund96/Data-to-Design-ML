# Notebooks

The notebooks contain saved datasets, audit tables, metrics, and figures from
the final experiment runs. The outputs can be viewed directly on GitHub or in
the VS Code Notebook Editor without executing the cells.

View them in this order:

1. [UCI linear baselines](week03_linear_family.ipynb)
2. [UCI feature representations](week04_representation_experiments.ipynb)
3. [UHPC import and target audit](week05_uhpc_import_and_target_check.ipynb)
4. [UHPC semantic missingness](week06_semantic_missingness_strategies.ipynb)
5. [UHPC row-mixed experiments](week07_linear_family_results.ipynb)
6. [Publication-held-out and LOPO evaluation](week08_publication_generalization.ipynb)
7. [Uncertainty calibration](week09_uncertainty_calibration.ipynb)
8. [SHAP and permutation attribution](week10_feature_attribution.ipynb)

Reusable processing and modeling code is stored in `src/s1_linear/`. The
optional reproduction commands are documented in the root `README.md`.
