# Section 4: Boosting Models

Experiments on gradient boosting algorithms (XGBoost, HistGradientBoosting, AdaBoost) for concrete strength prediction on UCI and UHPC datasets.

- **Week 1–4**: UCI dataset baselines, data cleaning, monotonic physical constraints, and sample weighting.
- **Week 5–7**: UHPC dataset preprocessing, feature missingness policies, scikit-learn pipelines, and hyperparameter tuning.
- **Week 8–10**: Group-aware validation (LOPO), quantile regression uncertainty intervals, and SHAP interpretability.
